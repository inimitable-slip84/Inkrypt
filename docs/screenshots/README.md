# Screenshot assets

Place **PNG** or **JPEG** files here for documentation and the GitHub README, for example:

- `vault-overview.png`
- `add-entry.png`
- `settings.png`

See **[Screenshots guide](../screenshots.md)** for Chrome Web Store sizes, naming ideas, and safety tips (no real secrets in images).

This folder is optional until you add images; you can commit it empty or add `.gitkeep` if your tooling requires a non-empty directory.
